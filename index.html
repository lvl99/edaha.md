edaha.md

Simple, clean and easy static site generator and CMS using markdown.

  • Use markdown to write articles
  • Define custom article types
  • Define custom embeds
  • Customise templates with Nunjucks for all or specific article types
  • Output to any text format (HTML, RSS XML, JSON, etc…)
  • WYSIWYG editor
