# About

**edaha.md** (styled all lowercase) is a static site generator written in TypeScript that processes markdown files and outputs HTML and RSS XML files.

It was born from an idea that simple is beautiful. It's aim is to be easy and quick to use.

Static site generation means all pages are pre-compiled — the server only needs to serve them. This should reduce load times for visitors and reduce electricity and processing power for client and server alike.

Using markdown means writing articles can be done using a basic text editor.

edaha.md was created by Matt Scheurich at LVL99 using the [Apache 2.0 license](https://github.com/lvl99/edaha.md/blob/main/LICENSE). It is free open source software for anyone to use and extend.
