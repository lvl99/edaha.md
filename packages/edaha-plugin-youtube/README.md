# @lvl99dotcom/edaha-plugin-youtube

An [edaha.md](https://github.com/lvl99/edaha.md#readme) embed plugin for YouTube video players. It always embeds from youtube-nocookie.com, whatever form of YouTube URL is given.

```sh
npm add @lvl99dotcom/edaha-plugin-youtube --save-dev
```

```yaml
# edahaconfig.yml
plugins:
  - "@lvl99dotcom/edaha-plugin-youtube"
```

```md
<!-- embed:youtube -->https://www.youtube.com/watch?v=aju_UB5VIf8<!-- /embed:youtube -->
```

See [Embeds](https://lvl99.github.io/edaha.md/docs/07-embeds/) in the docs.
