Welcome

edaha.md v0.1.0 was launched as a simple approach to a static site generator, utilising markdown to then render articles into HTML and RSS XML files.

You can find out more on our About page, or on our Github repo.

edaha.md originally started as a simple and quick solution to have markdown files that could be easily converted to HTML for use in the LiveCanvas project.
